# Feather Bot 3.1.0

Changelog covers infrastructure migration to **AIC Cloud VPS (Paid)** for 24/7 high-availability hosting, New Year Cake static and decay formula pricing (Years 1–300), Year 100 non-existent cake handling, renamed `/claimed cakes` command, `/cake price` command, `/auction avg price` command, unified `/item price` command across Auction, Pets, and Bazaar markets, 14-day historical auction average pricing engine, custom exit emoji integration (`<:exit:1540003415860707429>`), reforge-stripped custom item pricing for Permafrost & Fermento armor, Fermento armor static price updates, Revenant & Reaper armor kill count valuation bonus capped at 500k kills, Magical Nametag custom-named pet pricing fixes, line-boundary safe text truncation, optimized 7-item networth pagination, ultra-slim auction store memory optimization, 15-second idle memory auto-purge timer, centralized `api.js` request enforcement across all bot commands, updated NPC crop sell prices and enchanted multipliers, clean plain-text select menu option labels, static price overrides for Frozen Hourglass (150M), Glacial Trident (205M), Shard of the Shredded (275M), & Reaper Orb (280M), universal custom price precedence rule, enhanced memory audit logging with session sweep metrics, and stability enhancements.

## Detailed Summary

Version 3.1.0 introduces major enhancements to bot infrastructure, item valuation, market pricing tools, central API request routing, memory management, interactive session lifecycle controls, and bot reliability.

The **Infrastructure & Hosting** has been upgraded:
- Migrated production bot hosting to **AIC Cloud VPS (Paid)**, providing high availability, low-latency network performance, dedicated compute capacity, and 24/7 continuous uptime.

The **Market & Valuation Commands** have been expanded:
- Added `/cake price year:<year>` with mandatory year parameter, enforcing 0 coins and non-existent item labeling for Year 100, year `<= 0`, and future SkyBlock years.
- Renamed `/cakes` to `/claimed cakes username:<name>` with compulsory username parameter.
- Added `/auction avg price item:<name>` powered by historical market auction data, returning 14-day average prices, lowest BIN, sales sample counts, and valuation source tags.
- Added `/item price type:<auction|pets|bazaar> item:<name> [rarity] [level] [candy]` for unified price lookups across SkyBlock markets with optional pet parameters.

The **Pricing Engine & Networth Calculations** have been significantly upgraded:
- Enforced universal **Custom Static Price Precedence**: Whenever an item's custom static price is higher than other calculation methods (Bazaar, 7d/14d Auction, NPC), the custom static price takes priority across networth, auction, bazaar, pet, and minion calculation modules.
- Added static prices and 7d average entries for **Frozen Hourglass** (150M), **Glacial Trident** (205M), **Shard of the Shredded** (275M), and **Reaper Orb** (280M) in `data/auction-7d-avg.json`, `data/items.json`, and `data/customPrices.js`.
- Updated NPC crop sell prices and enchanted multipliers (Wheat: 2 coins, Carrot: 3 coins, Potato: 2 coins, Pumpkin: 10 coins, Melon: 1 coin, Mushroom: 8 coins, Cactus: 2 coins, Beetroot: 2 coins, Sugar Cane: 2.5 coins) in `calc/ext.gadget.calculator-minion-packageFile-db.js.js` (`window.sellNPC`) and `data/npcPrices.json`.
- Reforge prefixes (e.g. `Fierce`, `Light`) are automatically stripped before pricing lookups, resolving missing prices for `Fierce Permafrost Armor` and `Light Fermento Armor`.
- Fermento armor static prices updated to 12M Helmet, 17M Chestplate, 14M Leggings, and 10M Boots.
- Added Revenant & Reaper armor kill count valuation (+66 coins/kill from `stats_booked` NBT attributes), capped at **500,000 kills** (33M max bonus).
- Fixed pet detection (`isPet`) and species candidate resolution for pets renamed with Magical Nametags (e.g. `"Fluffy"`, `"Sparky"`), enabling accurate pricing across all custom-named pets.
- Upgraded the auction average pricing engine from a 7-day to a **14-day historical window** (`14d Auction` source label).

The **API Architecture & UI Enhancements**:
- Centralized all outgoing external API requests through `utils/api.js` across all 55 command files, removing direct `axios` usages in command files.
- Enforced clean plain-text labels for all Discord select menu dropdown options (`StringSelectMenuBuilder`), preventing raw custom emoji strings in dropdown labels (fixed `/bzitem` candidate matching select menus).
- Integrated custom exit emoji (`<:exit:1540003415860707429>`) into `utils/emojis.js` (`uiMap`, `customMap`) and updated `createExitButton` across all interactive commands.
- Replaced character-index slicing (`slice(0, 1890)`) with line-boundary safe splitting (`split('\n')`), ensuring networth pages never cut off text or tags in the middle of a line.
- Adjusted networth category pagination to `7` items per subpage for clean Discord embed display.

The **Memory Guard & RAM Optimization**:
- Eager module loading eliminated for heavy snapshot dependencies.
- Replaced multi-map auction pricing stores with an ultra-slim single `byKey` map storing primitive numeric values, reducing active RAM footprint by >90%.
- Added an automatic 15-second idle auto-purge timer (`CACHE_IDLE_PURGE_MS = 15000`) that clears in-memory caches to `null` and invokes `global.gc()` after 15s of inactivity.
- Enhanced 5-minute memory guard logging in `index.js` and `utils/cache.js` to track and report exact counts of swept stale sessions (`Swept N stale session(s)`) and post-sweep heap deltas.

## Added

- Added `/cake price year:<year>` slash command returning static/decay prices and enforcing 0 coins for invalid/future/Year 100 cakes.
- Added `/claimed cakes username:<name>` slash command displaying player cake claim totals.
- Added `/auction avg price item:<name>` subcommand group returning 14-day average prices and lowest BIN.
- Added `/item price type:<auction|pets|bazaar> item:<name> [rarity] [level] [candy]` unified pricing command with optional pet parameters (`rarity`, `level`, `candy`).
- Added static custom price overrides for Frozen Hourglass (150M), Glacial Trident (205M), Shard of the Shredded (275M), and Reaper Orb (280M).
- Added custom exit emoji (`<:exit:1540003415860707429>`) to `utils/emojis.js` and updated `createExitButton`.
- Added 14-day historical auction date collector (`getLast14DateKeys`) and 14-day database query range in `utils/auction7dAverage.js`.
- Added 15-second idle auto-purge timer (`touchIdlePurgeTimer`) in `utils/auctionAveragePrice.js` for automatic cache clearance and V8 garbage collection.

## Changed

- Migrated production bot hosting environment to **AIC Cloud VPS (Paid)** for 24/7 dedicated hosting, high availability, and improved performance.
- Centralized all external API calls across commands to route strictly through `utils/api.js`.
- Updated custom price precedence logic: if a custom static price is higher than calculated prices from other methods (Bazaar, 7d/14d Auction, NPC), the custom price is used across all valuation modules.
- Updated NPC crop sell prices and enchanted multipliers (Wheat: 2, Carrot: 3, Potato: 2, Pumpkin: 10, Melon: 1, Mushroom: 8, Cactus: 2, Beetroot: 2, Sugar Cane: 2.5) in `calc/ext.gadget.calculator-minion-packageFile-db.js.js` and `data/npcPrices.json`.
- Removed emojis from select menu dropdown option labels across all commands and views (`buildItemSelect`, `profileView`, etc.).
- Renamed `/cakes` command to `/claimed cakes`.
- Updated custom item pricing lookup (`getCustomItemPrice`) and `enrichItemsWithPrices` to strip reforge prefixes (`stripReforgePrefix`).
- Updated Fermento armor static custom prices (12M Helmet, 17M Chestplate, 14M Leggings, 10M Boots).
- Updated Revenant & Reaper armor kill count valuation to cap effective kills at 500,000 (33M max bonus).
- Updated pet recognition (`isPet`) to check `petInfo`, `petRarity`, container placement, and parenthesized species extraction `(Species)` for Magical Nametag pets.
- Updated auction average price source label to `14d Auction`.
- Updated networth pagination item limit to `7` items per subpage.
- Updated networth page character truncation to split at clean line boundaries (`\n`) to prevent mid-text cutoffs.
- Updated `/help` command details in `commands/help.js` with `/claimed cakes`, `/auction avg price`, `/cake price`, and `/item price`.
- Updated memory guard audit logging to report exact session sweep counts and heap RAM deltas.

## Fixed

- Fixed direct `axios` usage in commands (`search`, `bazaar`, `leaderboards`, `report`) by centralizing all endpoint calls in `utils/api.js`.
- Fixed broken/raw custom emoji tags rendering inside Discord select menu option labels (`buildItemSelect` in `commands/bazaar.js`).
- Fixed missing prices for reforged items like `Fierce Permafrost Armor` and `Light Fermento Armor`.
- Fixed unpriced custom-named pets (e.g. `"Fluffy"`, `"Sparky"`) in player storage and inventories.
- Fixed Year 100 cake valuation and future/invalid cake year price calculations.
- Fixed abrupt mid-word text truncation on long networth pages.
- Fixed high idle RAM footprint by converting auction stores to ultra-slim single-map structures with 15s auto-purge garbage collection.
