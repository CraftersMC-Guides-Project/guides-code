# Feather Bot 1.0.0

Released till commit `3cc845a93555942bd274e8670ec5ee32a28d5f6f` (`3cc845a`) on 2026-05-14.

## Detailed Summary

Version 1.0.0 established Feather Bot as a full CraftersMC/SkyBlock utility bot. This release introduced the main Discord command framework, persistent local stores, API helpers, operator controls, account linking, leaderboards, Bazaar tools, auction browsing, Reality Shards helpers, generated auction visuals, and the first round of memory and runtime safeguards.

The release also turned several data-heavy workflows into interactive Discord experiences. Auctions gained category browsing, player-specific auction lookup, item lore, cached auction snapshots, and generated item cards. Bazaar gained price lookups, history graphs, mappings, alerts, spread and flip calculations, and Bazaar-driven minion calculator pricing. Leaderboards were expanded from a basic view into multi-page interactive data for collections, boss times, farming contests, pets, and user submissions.

Operationally, 1.0.0 added privacy/terms documents, runtime health metrics, richer presence, cache controls, webhook logging, memory protection, and safer command permissions. It also removed committed environment data and moved development configuration into `.env.dev`.

## Added

- Added the core Discord bot command system, command registration, and interaction routing used by all slash commands.
- Added account linking and account management with `/verify`, `/unlink`, `/account`, persistent account storage, and operator checks.
- Added OP management with `/addop` and shared operator storage.
- Added operator messaging with `/message`, including direct-message delivery and optional attachment support.
- Added live SkyBlock auction browsing through `/auctions`, including category filtering, UI controls, and auction details.
- Added `/playerauctions` to view auctions owned by a specific player.
- Added auction snapshot storage and cached auction data to support faster and richer auction workflows.
- Added auction item lore display so auction views can show item details instead of only summary metadata.
- Added generated auction item cards with stat icons, rarity assets, item sprites, and rendered visual output.
- Added Bazaar tooling under `/bz`, including item price views, price history graphs, flip calculations, top order views, mappings, and alerts.
- Added Bazaar history storage in `data/bazaar.db` and updated the Bazaar history API endpoint.
- Added Bazaar mapping storage in `data/bazaar-store.json` for personal/global aliases and alerts.
- Added corrected Bazaar spread calculation support.
- Added Bazaar price support inside the minion calculator so minion output could use current Bazaar-style pricing.
- Added the interactive `/minion calculator` command and supporting minion database changes.
- Added `/leaderboards` with interactive navigation for CraftersMC leaderboard data.
- Added multi-leaderboard data, collection leaderboards, boss-time leaderboards, farming contest leaderboards, and pet leaderboard data files.
- Added `/submitlb` for leaderboard submission workflows and stored submission data.
- Added verification support around leaderboard submissions.
- Added `/reality shards` with collected/missing shard views and stored Reality Shard coordinate data.
- Added `/search` for CraftersMC Wiki searches.
- Added `/ping` with bot latency and runtime health metrics.
- Added rich presence, including presence showing guild count.
- Added privacy policy and terms of service documents.
- Added CLI and script foundations for local/development workflows.
- Added webhook logging, runtime stats helpers, memory guard utilities, cache helpers, and report footer patching.
- Added item sprite, inventory image, and UI stat assets used by generated views.
- Added local data stores for accounts, operators, leaderboards, Bazaar data, auction snapshots, notifications, and runtime state.

## Changed

- Increased cache duration to one hour for profile-related flows.
- Updated profile-based commands so a username can be used without always requiring a profile ID.
- Improved command permission handling for operator-only and restricted flows.
- Reworked auction rendering to include richer item visuals, lore, and stat icons.
- Updated API helpers to support newer auction, Bazaar, leaderboard, and profile workflows.
- Updated local store modules for account, leaderboard, auction, Bazaar, operator, and runtime data.
- Updated the Bazaar API logic for item resolution, aliases, spread values, and history support.
- Updated the profile view to include Reality Shards-related data.
- Moved development configuration into `.env.dev`.
- Removed committed `.env` data and added ignore coverage for sensitive environment files.
- Tuned cache and memory behavior to keep memory pressure lower during data-heavy commands.

## Fixed

- Fixed Bazaar command behavior and Bazaar spread/flip calculation issues.
- Fixed collection leaderboard entries that were not showing all items.
- Fixed command permission issues around restricted actions.
- Fixed missing minion data handling during calculator flows.
- Fixed SVG/rendering support used by generated images.
- Fixed several auction data, leaderboard data, and Bazaar data issues during the 1.0.0 cycle.
- Fixed memory pressure by tightening cache clearing and memory guard behavior.
- Reverted memory-heavy changes that caused runtime pressure.
