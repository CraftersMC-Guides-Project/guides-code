# Feather Bot 3.0.0

Last commit covered: `a3dadde`.

Changelog covers API usage reporting, ended-auction ingestion, command loading UI improvements, Discord Activity launch support for Reality Shards, WASM-rendered transparent item lore cards, extended SkyBlock inventory decoding, standardized reload controls, Networth engine overhaul with paginated button navigation, real-time Bazaar pricing prioritization, 7-day auction average ingestion, pet base pricing system with candy detection, and API retry resilience.

## Detailed Summary

Version 3.0.0 expands Feather Bot with better operational visibility, richer inventory decoding, enhanced auction UI features, standardized UI controls, a complete overhaul of the Networth & Storage Valuation system, real-time Bazaar pricing integration, and an expanded Pet Price Calculator.

The `/usage` command summarizes CraftersMC API usage across tracked endpoint groups, helping operators understand total requests, profile/player lookups, auction traffic, bazaar traffic, and the most requested endpoint.

Auction history collection now supports ended-auction ingestion. Background scripts fetch ended auctions from the CraftersMC API, save them into the Whale auction-history database, deduplicate seen auction IDs, and run continuously for background collection.

Auction item lore rendering generates transparent SVG/PNG item cards via `@resvg/resvg-wasm` loaded with custom pixel font `PixeloidSans.ttf`. Plain text codeblock lore displays have been replaced with a clean graphical card experience.

The `/auctions` command supports time-based sort modes (**Ending Soon** and **Just Started**), featuring dynamic button state indicators and custom UI clock emojis (`<:clock:1494916727270543380>`).

The SkyBlock profile inventory system (`/inventory`) decodes and renders 16 distinct inventory types, including **Equipment**, **Wardrobe**, **Backpacks**, **Candy Bag**, **Trick or Treat Bag**, **Pumpkin Ammo**, and **Saved Effects**, accessible via a dropdown select menu (`Select inventory tab...`) alongside quick-action buttons.

UI refresh controls across all commands have been unified into a standardized **Reload Button** using custom emoji (`<:reload:1532009712458141848>`), integrated directly into bottom navigation action rows.

Reality Shards includes a Discord Activity launch button (`View in Discord Activities`), enabling users to open the embedded Activity directly from `/reality shards`.

The `/networth` command has been redesigned into a multi-page interactive interface featuring **7 category pages** (`Overview & Networth`, `Inventory & Armor`, `Ender Chest`, `Accessory Bag`, `Quiver & Cake Bag`, `Pets`, `Wardrobe & Other Storage`). Every page displays a sticky summary showing Purse Coins, Bank Balance, Cash Total, Storage Items Value, and Estimated Total Networth alongside page-specific total values.

Pricing logic now prioritizes real-time Bazaar market prices before checking auction data. Enchantment books (e.g., `Smite VI Enchant Book`, `Turbo-Mushroom I Enchant Book`) are automatically parsed and matched to Bazaar product IDs (`smite_6`, `turbo_mushroom_1`).

Auction pricing strictly utilizes **7-day average historical data** (`7d-avg`) and soulbound items. The 7-day average engine dynamically discovers and ingests the 7 most recent daily snapshot files from the GitHub repository (`CraftersMC-Guides-Project/auction`), with prefix fallback matching for reforge-stripped tools (e.g. `Double-bit Melon Dicer` → `Melon Dicer 3.0`).

The Pet Pricing system has been upgraded with **Pet Base Prices** (`PET_BASE_PRICES`) per rarity tier, calculating `Total Price = Base Price + (EXP * Coin/EXP)`. It features automatic **Pet Candy detection** from item NBT/lore, adjusts coin/EXP rates for candied pets, supports 3 new pets (**Bat**, **Black Cat**, **Skeleton Horse**), and strictly enforces valid rarities per pet type.

- Added `saveEndedAuctions` for ended-auction persistence, deduplication, and market snapshot generation.
- Added custom TTF font loading (`PixeloidSans.ttf`) into `@resvg/resvg-wasm` font cache for auction item lore cards.

- Added `ENDING_SOON` and `JUST_STARTED` sort modes to `/auctions`.
- Added dynamic clock emoji (`<:clock:1494916727270543380>`) indicators for time-based auction sorting.

- Added a standardized Reload button (`<:reload:1532009712458141848>`) placed in bottom navigation bars across `/player`, `/cosmetics`, `/cakes`, `/playtime`, `/rankhistory`, `/status`, `/usage`, `/networth`, `/reality`, `/auctions`, and `/playerauctions`.
- Added a `View in Discord Activities` button to `/reality shards`.
- Added Discord Activity launching through `interaction.launchActivity()`.
- Added a command loading progress UI for slash commands.
- Added 7-page paginated navigation to `/networth` using `Next` and `Previous` button controls.

- Added Bazaar market price prioritization for all non-pet items before checking auction historical averages.
- Added Roman numeral and regex parsing (`nameToBazaarId`) to match Enchantment Books to Bazaar product IDs.
- Added in-flight Promise deduplication (`getBazaarCatalogSet`) for Bazaar catalog product fetching.

- Added `(Candied)` label and modified coin/EXP rates for candied pets in `/networth` and pet calculation outputs.
- Added 3 new pets: **Bat**, **Black Cat**, and **Skeleton Horse**.
- Added pet rarity validation to reject non-existent rarities for specific pets (e.g., rejecting `Common` for `Blaze` or `Ender Dragon`).
- Added retry wrapper (`requestWithRetry`) and detailed error handling (429 rate limit retry-after, 404 handling) to `fetchProfile()`.
- Exported `writeJsonAtomic` from `utils/auctionSnapshot.js` and added `dotenv` initialization to `scripts/calculate-7d-avg.js`.

## Changed

- Removed outer stroke borders from lore card SVG image generation.
- Moved refresh/reload buttons from isolated top action rows into bottom navigation rows.
- Updated auction history snapshot saving to keep ended auctions only unless the source is explicitly marked as ended.
- Updated Reality Shards Activity launch buttons to use a stateless custom ID that does not include usernames or profile IDs.
- Updated component routing so the stateless Reality Shards Activity button can be used without the original command-owner restriction.
- Updated global command registration to preserve the app's Primary Entry Point command during bulk overwrites.
- Updated interaction reply handling to sanitize undefined payload fields and normalize Components V2 replies.
- Removed single dropdown menu from `/networth` in favor of paginated button navigation.
- Removed live auction fallback from networth calculations to strictly enforce 7-day average (`7d-avg`) historical data.
- Fixed `New Year's Cake Bag` valuation so cake bags are priced via auction averages while individual `New Year Cake` items remain excluded (0 coins).
- Refactored `stripReforgePrefix` handling across Bazaar, auction, and pet calculations.
- Cleaned pet base price structures to only list existing valid rarities per pet type.
