# Feather Bot 2.2.0

Last commit covered: `e09b645`.

Changelog covers everything after `6c1d309`, including the later auction alert, leaderboard, pet price, and auction-history control work.

## Detailed Summary

Version 2.2.0 introduces Whale, the Wide-scale Historical Auction Logging and Extraction layer for Feather Bot. Whale is the auction-market history foundation that powers auction alerts in the same spirit as the existing Bazaar alert command.

Auction snapshots now feed a compact historical auction database. Each successful scheduler run extracts lightweight auction observations and per-item market summaries, making it possible to compare alert thresholds against recent BIN and bid floors without keeping raw NBT-heavy auction payloads in the alert path.

The new history layer stores both detailed observations and fast market summaries. This gives future auction alert logic a simple query surface for item floors, averages, counts, rarity, category, and recent history.

Users can now create, list, and remove auction price alerts through `/auction alert`. Alerts can watch either BIN floor or normal-auction bid floor prices.

## Added

- Added the Whale branding asset for Wide-scale Historical Auction Logging and Extraction.
- Added compact historical auction logging in `data/auction-history.db`.
- Added per-auction observation extraction from live auction snapshots.
- Added per-item auction market snapshots with BIN floor, bid floor, averages, counts, rarity, and category metadata.
- Added auction history query helpers for future auction price alert checks.
- Added auction history stats helpers for verifying tracked samples, market snapshots, item count, and observed time range.
- Added `/auction alert` with add, list, and remove actions.
- Added persistent auction alert storage in `data/auction-alerts.json`.
- Added background auction alert checks using the latest Whale market snapshots.
- Added `AUCTION_HISTORY_DB_PATH` support for overriding the auction history database path.
- Added a pet price calculation script for estimating pet values from auction data and related pricing inputs.

## Changed

- Updated auction snapshot writes so each successful scheduler run also extracts historical auction observations.
- Added `DISABLE_AUCTION_HISTORY_LOG=1` as an escape hatch for disabling auction history extraction.
- Updated auction scheduler logging to include auction history extraction results.
- Updated leaderboard submission handling to create profile diff elements for profile-based leaderboard entries.
- Updated auction history persistence to honor a shared environment toggle for enabling or disabling database writes from auction snapshot processing.
- Updated privacy documentation to list compact auction market history built from public auction listings.
