# Feather Bot 3.2.0

Changelog covers the dynamic Bazaar and Auction recipe craft price engine (`utils/recipePrice.js`), crafting cost & profit calculator (`/craft`), minion daily profit and upgrade calculator (`commands/minion.js`), administrative missing emoji log viewer (`/logs`), leaderboard submission processing (`/submit`), event notification rules (`/notify`), expanded pet valuation formulas, massive emoji system overhaul with over 500 custom item mappings (`utils/emojis.js`), complete SkyBlock item and recipe database additions (`data/itemRecipe.json`, `data/minions.json`, `data/armor.json`, `data/swords.json`, `data/tools.json`, `data/accessories.json`), 3,500+ asset images, player profile loading fixes, min/max craft cost calculations, Discord 3-second interaction token timeout fixes, dual Bazaar/Auction price display integration, seamless round-trip Back button navigation, and API proxy routing optimizations.

## Detailed Summary

Version 3.2.0 is a major feature update introducing dynamic crafting cost calculations, crafting profit modeling, minion profit modeling, bot diagnostic logging, leaderboard submission integration, an extensive SkyBlock item database, and a massive visual upgrade with custom item emojis and texture assets.

The **Recipe Craft Pricing Engine** (`utils/recipePrice.js` & `commands/craft.js`):
- Implemented a recursive crafting calculation engine (`getRecipeCraftPrice`) that dynamically evaluates item craft costs from `data/itemRecipe.json` up to 4 sub-recipe tiers deep.
- Multi-channel price evaluation across Bazaar instant buy / buy orders, NPC merchant sell values (`data/npcPrices.json`), and Auction BIN / average prices.
- Computes both **minimum craft cost** (using lowest BIN / buy order prices) and **maximum craft cost** (using average BIN / instant buy prices), exposing exact cost ranges (`minCraftCost`, `maxCraftCost`) for crafted items.
- Introduced the `/craft` command and crafting profit evaluator (`calculateCraftCostAndProfit`):
  - Excluded static custom prices (`includeCustomPrice = false`) from crafting profit/loss calculations so static overrides don't distort live market crafting margins.
  - Restricted output item market value evaluation (`onlyBazaarOr14dAuction = true`) strictly to direct Bazaar data or 14-day auction averages, displaying explicit unpriced warnings when historical auction data is missing.
- Integrated recipe craft pricing directly into `/item`, `/bazaar`, `/auction`, `/craft`, and `/networth` command outputs.

The **Unified Item Price & Market Display** (`commands/auction.js` & `commands/item.js`):
- Dual Price Display: When running `/item price type:auction` (or `/auction`), if an item has a Bazaar recipe craft cost AND is present in 14-day auction average data, both the **Bazaar Recipe Craft Cost** and **14-Day Direct Auction Avg** (with Lowest BIN and sales count) are displayed simultaneously on the same card.
- 360-Degree Interactive Button Navigation: Added an interactive **Back** button (`<:back2:1494916673721864232>`) to `/recipe` cards that returns directly to the **Item Price & Valuation Summary** card on a single press, alongside **Back to Recipe** controls on `/craft`.

The **Discord Interaction Timeout & Stability Fixes**:
- Added `safeDeferUpdate()` across button and dropdown component handlers (`commands/craft.js`, `commands/recipe.js`, `commands/auction.js`) catching Discord API error codes `10062` (Unknown Interaction) and `40060` (Interaction already acknowledged).

The **Minion Calculator & Economic Valuation** (`commands/minion.js` & `data/minions.json`):
- Expanded the `/minion` command powered by a new structured database (`data/minions.json`) covering 1,700+ minion tiers across farming, mining, combat, foraging, and fishing categories.
- Calculates exact tier upgrade costs, required crafting materials, daily output quantities, fuel speed multipliers, automated shipping unit prices, and net daily coin profit.
- Computes complete minion setup networth valuations and recipe craft costs for minion tier progression.

The **Emoji System & Visual Assets Expansion** (`utils/emojis.js` & `assets/images/`):
- Overhauled `utils/emojis.js` with 500+ new custom SkyBlock item emoji mappings, mapping item keys to custom Discord item icons for rich embed layouts.
- Added 3,500+ item texture asset images under `assets/images/` covering SkyBlock weapons, armor sets, accessories, minions, and mob drops.
- Integrated dynamic `getItemEmoji()` lookup across all bot slash commands, select menus, containers, and embed displays.

The **Bot Diagnostics & Administration** (`commands/logs.js`):
- Introduced the `/logs` slash command restricted to bot administrators (`PermissionFlagsBits.Administrator`).
- Supports viewing (`/logs action:view`) runtime missing item emoji logs or clearing (`/logs action:clear`) the logged unmapped item list.
- Automated message chunking ensuring log outputs exceeding 1,700 characters are safely split across multiple ephemeral Discord responses.

The **Leaderboard & Player Profile Enhancements** (`commands/submit.js`, `commands/player.js` & `leaderboards/`):
- Added the `/submit` slash command enabling players to submit scores and achievements to global leaderboards.
- Refactored player profile data fetching in `/player` to resolve profile loading failures and optimize profile summary displays.
- Updated `leaderboards/src/lb/multi-lb-data.js` and `leaderboards/src/lb/updated_collections.js` for multi-leaderboard score tracking.

The **Auction Alerts & Notification System** (`commands/notify.js` & `utils/auctionAlertStore.js`):
- Upgraded `/notify` command and alert store to handle event notifications for Jacob's Farming Contest, Travelling Zoo, New Year Celebrations, Season of Jerry / Pig events, and Spooky Festivals.
- Refactored auction price alert tracking and notification delivery.

The **Pet Valuation & System Stability**:
- Fixed pet price calculation anomalies (`fixed petprices`) in `commands/pet.js` and `commands/networth.js`.
- Refactored pet detection and species parsing in `utils/inventoryDecoder.js` to accurately evaluate pet skins, pet items, held candy penalties, and base tier valuations.
- Fixed component interaction dropdown routing (`StringSelectMenuInteraction`) in `/auction` price lookups.
- Optimized proxy URL API requests and numeric item ID translations (`utils/numericItemIds.js`).
