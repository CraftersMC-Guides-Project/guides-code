# Feather Bot 2.1.0

Last commit `6c1d309` on 2026-06-3.

Changelog covers everything after `50b416e`.

## Detailed Summary

Version 2.1.0 focused on making Bazaar and auction data easier to inspect and reuse. Bazaar item views gained a new history workflow that lets users open a date picker-style modal from `/bz item`, enter a UTC date, and see that day's history graph plus buy, sell, 7-day average, demand, and supply changes across the available history.

The minion ranking and calculator Bazaar logic was also tightened. Produced minion drops now resolve through global Bazaar mappings, hard-coded item ID overrides, normalized aliases, and multiple fallback candidates instead of relying on one normalized name. This improves pricing for awkward item names such as mushrooms, raw mob drops, melon slices, redstone dust, slimeballs, and dye-related drops. Top-minion rankings now distinguish between items that are not Bazaarable and Bazaar lookups that were temporarily unavailable, instead of silently treating missing Bazaar data like NPC fallback pricing.

Operationally, 2.1.0 added better guild/server CLI. The auction snapshot scheduler now saves a persistent `data/item.json` catalog of unique decoded auction item names, merging new names across runs so auction data can feed future search, autocomplete, mapping, or item-discovery work.

Profile farming-contest views now show readable bracket names instead of raw bracket numbers, so highest brackets and bracket-hit lists display values like Participated, Bronze, Silver, Gold, Platinum, and Diamond.

SkyBlock profile browsing also gained direct slash commands for individual profile categories. Instead of opening `/player`, selecting a profile, and then switching the category menu, users can now jump straight into inventory, wardrobe, collections, farming contests, API settings, skills, slayer, bosses, combat, quests, minions, experiments, perks, relationships, profile metadata, and former-member views with a username and optional profile hint.

- Added Bazaar item ID resolution helpers for minion-produced item names.
- Added global Bazaar mapping support inside minion Bazaar price resolution.
- Added explicit minion Bazaar item ID overrides for items whose display names do not directly match Bazaar IDs.
- Added combined mushroom expansion so red/brown mushroom outputs are priced separately where needed.

- Added 429 retry handling for safe Bazaar item-detail requests.
- Added top-minion Bazaar lookup concurrency limiting.

## Changed

- Updated Bazaar item panels so overview, graph, top orders, flip value, and history are available from the same interactive panel.
- Updated Bazaar history behavior from a single closest snapshot lookup into a full-day timeline summary.
- Updated Bazaar history timestamps to support multiple possible API timestamp field names.
- Updated Bazaar graph generation to use the shared timestamp parser for more reliable history rendering.
- Updated Bazaar command help and `readme.txt` to document the new item history workflow.
- Updated CLI guild and server commands to fetch all guild summaries before displaying counts or lists.
- Updated top-minion rankings to rank by Bazaar sell-instantly value without hiding missing Bazaar items behind NPC fallback totals.
- Reduced the default top-minion page size to 5 entries so richer per-item price detail fits cleanly in Discord messages.
- Updated top-minion output to show Bazaar sell-order totals, NPC totals, top drop prices, and missing/unavailable Bazaar status more clearly.
- Updated minion calculator Bazaar pricing to try multiple possible item IDs before giving up.
- Updated minion calculator produced-item handling so combined drops can be expanded before Bazaar pricing.
- Updated Bazaar safe fetches to return `null` for invalid item ID responses as well as 404s.
- Updated auction snapshot writes so each scheduler run refreshes both `data/auction.json` and the auction item-name catalog.
- Updated Farming Contest profile bracket displays to show bracket names instead of numeric IDs.
- Updated profile inventory category rendering so the `Other` inventory tab is treated as text-based storage data, allowing `/wardrobe` to show decoded other-inventory entries without expecting an image attachment.
- Updated `/help` and `readme.txt` to document the new direct SkyBlock profile category commands.
- Updated data snapshots for auctions, Bazaar history storage, and notification database state as part of the release cycle.

## Fixed

- Fixed top-minion Bazaar pricing for minion drops that did not resolve through simple normalized item names.
- Fixed minion Bazaar pricing for combined mushroom drops.
- Fixed minion Bazaar pricing for several display-name-to-Bazaar-ID mismatches, including melon, cactus dye, raw mob drops, slimeball, and redstone dust.
- Fixed top-minion output that previously made missing Bazaar prices look like NPC fallback pricing.
- Fixed top-minion behavior under Bazaar rate limits by marking temporarily unavailable lookups separately.
- Fixed safe Bazaar item-detail fetching for `invalid_item_id` responses.
- Fixed Bazaar historical date handling so invalid dates and unavailable days return clearer errors.
- Fixed Bazaar history controls by routing `bzhist:` buttons and modal submissions through the Bazaar command handler.
- Fixed CLI guild/server listing so larger guild lists are fetched directly from Discord instead of depending on a partial cache.
- Fixed direct wardrobe-style inventory viewing by avoiding image attachment generation for unsupported `Other` inventory storage.
