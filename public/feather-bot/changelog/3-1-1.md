# Feather Bot 3.1.1

Changelog covers auto-updating SkyCalendar component v2 setup command (`/set skycalendar`) for server admins with 5-minute background refresh, global user access for calendar Refresh button, custom announcement emoji integration (`<:announcement:1540752855617507398>`), formatted item display name resolution in `/item` and `/auction` price commands, Bazaar API product ID lowercase normalization fixing `400 invalid_item_id` proxy errors, NBT `extraAttributes.petInfo` JSON string decoding, lore species recognition (`extractPetTypeFromLore`) for custom-named pets (e.g. Tiger named *Yoruichi*), calculated pet rarity precedence (`petCalcResult.rarity`), and tightened custom price substring matching to prevent base item names matching compound armor entries.

## Detailed Summary

Version 3.1.1 introduces server administrator tooling for live SkyBlock calendar tracking, improved market item name formatting, critical Bazaar API case-sensitivity fixes, enhanced custom pet species and rarity recognition, and precision custom item price matching.

The **SkyCalendar System** has been upgraded:
- Added `/set skycalendar` slash command restricted to server administrators to deploy live-updating SkyCalendar component v2 messages that automatically refresh every 5 minutes.
- Unlocked calendar **Refresh** button permissions so any server member can trigger instant on-demand updates.
- Removed the Farming Contest button builder from the primary calendar component payload.

The **Bazaar & Market Pricing Architecture** has been enhanced:
- Fixed an issue where uppercase Bazaar product IDs (`CACTUS`, `FERMENTO`) returned `400 Bad Request (invalid_item_id)` from the proxy API. Product IDs are now normalized to lowercase in `utils/bazaarApi.js` and `commands/networth.js`, ensuring Bazaar items reliably fetch current Bazaar prices rather than falling back to 14-day auction averages.
- Tightened substring matching in `data/customPrices.js` (`getCustomItemDetails`) so base raw materials (e.g. `Fermento`) no longer falsely match compound custom price entries (e.g. `Fermento Boots`).
- Updated `/item` and `/auction` commands so raw search queries (e.g. `axe of the`) display clean, formatted display names (`Axe of the Shredded`) in embed header tags and component labels.

The **Pet Calculation Engine** has been significantly upgraded:
- Added `extractPetTypeFromLore()` in `utils/inventoryDecoder.js` to extract pet species directly from lore headers (`<Species> - <Category> Pet`), allowing custom-named pets (e.g. a Tiger pet named *Yoruichi*) to correctly identify their species and evaluate as **`[LEGENDARY] Tiger ([Lvl 100] Yoruichi)`**.
- Added NBT JSON string parsing for `extraAttributes.petInfo` in `commands/networth.js` to reliably extract pet tier, level, and XP.
- Enforced `petCalcResult.rarity` precedence over raw item fallbacks, ensuring pets with 3 abilities or calculated legendary status display as **`[LEGENDARY]`**.

The **Branding & UI Enhancements**:
- Added custom announcement emoji (`<:announcement:1540752855617507398>`) to `utils/emojis.js` (`customMap`, `uiMap`).
- Updated header text banners in `utils/announcement.js` to display the new custom announcement emoji.

## Added

- Added `/set skycalendar` slash command (admin only) for setting up 5-minute auto-updating SkyCalendar component messages.
- Added custom announcement emoji (`<:announcement:1540752855617507398>`) in `utils/emojis.js`.
- Added `extractPetTypeFromLore()` in `utils/inventoryDecoder.js` to detect pet species from lore text headers.
- Added NBT JSON string parsing for `extraAttributes.petInfo` in `commands/networth.js` (`calculatePetPriceFromItem`).

## Changed

- Unlocked calendar **Refresh** button interaction so any user can refresh calendar components.
- Removed Farming Contest button from `buildCalendarPayload` in `commands/skycalender.js`.
- Updated header banners in `utils/announcement.js` to use the custom announcement emoji.
- Normalized Bazaar API item IDs to lowercase in `utils/bazaarApi.js` (`fetchItemDetails`) and `commands/networth.js` (`getBazaarPrice`).
- Tightened substring matching in `data/customPrices.js` (`getCustomItemDetails`) to prevent shorter base item keys matching longer compound item entries when the length difference exceeds 3 characters.
- Enforced `petCalcResult.rarity` precedence in `commands/networth.js` to prevent un-decoded items from reverting to `COMMON`.
- Updated `/item` and `/auction` command handlers to display formatted item names (`priceData.name`) in component headers.

## Fixed

- Fixed `400 invalid_item_id` errors when querying Bazaar API with uppercase product IDs.
- Fixed Bazaar items (e.g. `Cactus`, `Fermento`) improperly defaulting to 14-day auction average valuations.
- Fixed `Fermento` matching `Fermento Boots` and evaluating at 10M static price.
- Fixed custom-named pets (e.g. `Yoruichi`) failing species detection and displaying as generic or incorrectly valued pets.
- Fixed pet rarity displaying as `[COMMON]` for legendary pets lacking explicit `petRarity` root tags.
- Fixed raw search input strings showing in `/item` and `/auction` component outputs.
