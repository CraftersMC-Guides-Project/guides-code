# Feather Bot 3.1.1

Changelog covers auto-updating SkyCalendar component v2 setup command (`/set skycalendar`) for server admins with 5-minute background refresh, global user access for calendar Refresh button, custom announcement emoji integration (`<:announcement:1540752855617507398>`), formatted item display name resolution in `/item` and `/auction` price commands, Bazaar API product ID lowercase normalization fixing `400 invalid_item_id` proxy errors, NBT `extraAttributes.petInfo` JSON string decoding, lore species recognition (`extractPetTypeFromLore`) for custom-named pets (e.g. Tiger named *Yoruichi*), calculated pet rarity precedence (`petCalcResult.rarity`), tightened custom price substring matching to prevent base item names matching compound armor entries, refactored custom price helper functions into `utils/customPrices.js`, pet skin valuation attributes, Components v2 layout enhancements, `/player` data fetching, `/submit` leaderboard processing, and critical interaction component router fixes for `/item` and `/auction` fuzzy matching dropdown menus.

## Detailed Summary

Version 3.1.1 introduces server administrator tooling for live SkyBlock calendar tracking, improved market item name formatting, critical Bazaar API case-sensitivity fixes, enhanced custom pet species and rarity recognition, precision custom item price matching, modular architecture refactoring for custom prices, leaderboard processing, and fixes for Discord component interaction routing.

The **SkyCalendar System** has been upgraded:
- Added `/set skycalendar` slash command restricted to server administrators to deploy live-updating SkyCalendar component v2 messages that automatically refresh every 5 minutes.
- Unlocked calendar **Refresh** button permissions so any server member can trigger instant on-demand updates.
- Removed the Farming Contest button builder from the primary calendar component payload.

The **Bazaar & Market Pricing Architecture** has been enhanced:
- Fixed `/item` and `/auction` fuzzy match candidate select menus: updated `index.js` component router check from `if (interaction.isButton())` to `if (interaction.isMessageComponent())`, enabling `StringSelectMenuInteraction` events (`aucavg:select:`) to route properly to `auctionCommand.handleComponentInteraction`.
- Resolved Discord API `400 Bad Request` (`Invalid Form Body - flags`) errors during component interaction updates by stripping the `flags` parameter when calling `interaction.editReply()` or `interaction.update()`.
- Added immediate `interaction.deferUpdate()` handling on candidate select menu interactions to eliminate Discord 3-second interaction timeouts.
- Resolved item candidate selection when `selectedFromSelect` is true, ensuring the selected candidate name (e.g. `Axe of the Shredded`) is passed to `getAuctionAveragePrice` and properly formatted.
- Added comprehensive diagnostic console logging (`[index.js]`, `[aucavg]`) for candidate select menu lifecycle debugging.
- Fixed an issue where uppercase Bazaar product IDs (`CACTUS`, `FERMENTO`) returned `400 Bad Request (invalid_item_id)` from the proxy API. Product IDs are now normalized to lowercase in `utils/bazaarApi.js` and `commands/networth.js`, ensuring Bazaar items reliably fetch current Bazaar prices rather than falling back to 14-day auction averages.
- Refactored `data/customPrices.js` to serve strictly as a data dictionary for static item valuations, cake prices, and display names, moving all helper functions into a dedicated `utils/customPrices.js` module.
- Updated all dependent commands (`/auction`, `/bazaar`, `/cake`, `/custom`, `/item`, `/minion`, `/networth`, `/pet`) and `utils/auctionAveragePrice.js` to utilize `utils/customPrices.js`.
- Untracked `data/customPrices.js` from the Git repository index so `.gitignore` rules apply properly.
- Tightened substring matching in `utils/customPrices.js` (`getCustomItemDetails`) so base raw materials (e.g. `Fermento`) no longer falsely match compound custom price entries (e.g. `Fermento Boots`).
- Added static valuations for pet skins (e.g. `watermelonocelotpetskin`, `silverfishpartybugpetskin`).
- Updated `/item` and `/auction` commands so raw search queries (e.g. `axe of the`) display clean, formatted display names (`Axe of the Shredded`) in embed header tags and component labels.
- Integrated Discord Components v2 layouts across auction average price views and Bazaar UI flows.

- Expanded static NPC merchant seller pricing database in `data/npcPrices.json` covering 25 CraftersMC NPC merchants (James, Milo, Rowan, Parker, Adam, Braum, Hopkins, Buzz, Reed, Tyler, Julia, Nyko, Viking, Vael, etc.) with 80+ new items and price updates.
- Added Bazaar item craft recipes mapping database in `data/itemRecipe.json` detailing ingredient component counts across farming, mining, combat, foraging, and oddities categories.

The **Pet Calculation Engine** has been significantly upgraded:
- Added `extractPetTypeFromLore()` in `utils/inventoryDecoder.js` to extract pet species directly from lore headers (`<Species> - <Category> Pet`), allowing custom-named pets (e.g. a Tiger pet named *Yoruichi*) to correctly identify their species and evaluate as **`[LEGENDARY] Tiger ([Lvl 100] Yoruichi)`**.
- Added support for pet skin attributes and skin pricing in networth calculations.
- Added NBT JSON string parsing for `extraAttributes.petInfo` in `commands/networth.js` to reliably extract pet tier, level, and XP.
- Enforced `petCalcResult.rarity` precedence over raw item fallbacks, ensuring pets with 3 abilities or calculated legendary status display as **`[LEGENDARY]`**.

The **Player & Leaderboard Management** features:
- Implemented `/player` command enhancements for profile data fetching and status rendering.
- Implemented `/submit` command for user leaderboard score submissions and multi-leaderboard data processing.

The **Branding & UI Enhancements**:
- Added custom announcement emoji (`<:announcement:1540752855617507398>`) to `utils/emojis.js` (`customMap`, `uiMap`).
- Updated header text banners in `utils/announcement.js` to display the new custom announcement emoji.

## Added

- Added `/set skycalendar` slash command (admin only) for setting up 5-minute auto-updating SkyCalendar component messages.
- Added new utility module `utils/customPrices.js` containing pricing calculations, display name formatting, and file storage handlers.
- Added `data/itemRecipe.json` containing structured Bazaar item crafting recipes and required ingredient counts across all Bazaar categories (farming, mining, combat, foraging, oddities).
- Added 80+ new CraftersMC NPC merchant seller item price entries in `data/npcPrices.json` covering reforge items, Tuxedo armor, Spooky event items, pets, and tools.
- Added custom price entries for pet skins (e.g. `Watermelon Ocelot Pet Skin`, `Silverfish Party Bug Pet Skin`).
- Added `/submit` command for processing leaderboard score submissions.
- Added custom announcement emoji (`<:announcement:1540752855617507398>`) in `utils/emojis.js`.
- Added `extractPetTypeFromLore()` in `utils/inventoryDecoder.js` to detect pet species from lore text headers.
- Added NBT JSON string parsing for `extraAttributes.petInfo` in `commands/networth.js` (`calculatePetPriceFromItem`).
- Added diagnostic logging in `index.js` and `commands/auction.js` for select menu interaction tracking.

## Changed

- Refactored `data/customPrices.js` to export pure data maps (`CUSTOM_PRICES`, `NEW_YEAR_CAKE_PRICES`, `CUSTOM_PRICE_NAMES`), moving function logic to `utils/customPrices.js`.
- Updated commands (`/auction`, `/bazaar`, `/cake`, `/custom`, `/item`, `/minion`, `/networth`, `/pet`) and `auctionAveragePrice.js` to load from `utils/customPrices.js`.
- Updated `index.js` component router check to `if (interaction.isMessageComponent())`, ensuring select menu interactions (`StringSelectMenuInteraction`) are routed properly alongside buttons.
- Enforced `.gitignore` rules for `data/customPrices.js` by untracking it from the Git index.
- Unlocked calendar **Refresh** button interaction so any user can refresh calendar components.
- Upgraded `/auction` and `/bazaar` views to support Discord Components v2 layouts.
- Enhanced `/player` command data fetching and profile summary displays.
- Removed Farming Contest button from `buildCalendarPayload` in `commands/skycalender.js`.
- Updated header banners in `utils/announcement.js` to use the custom announcement emoji.
- Normalized Bazaar API item IDs to lowercase in `utils/bazaarApi.js` (`fetchItemDetails`) and `commands/networth.js` (`getBazaarPrice`).
- Tightened substring matching in `utils/customPrices.js` (`getCustomItemDetails`) to prevent shorter base item keys matching longer compound item entries when the length difference exceeds 3 characters.
- Enforced `petCalcResult.rarity` precedence in `commands/networth.js` to prevent un-decoded items from reverting to `COMMON`.
- Updated `/item` and `/auction` command handlers to display formatted item names (`priceData.name`) in component headers.

## Fixed

- Fixed select menu dropdown interactions (`aucavg:select:`) in `/item` and `/auction` failing with "The bot didn't respond" errors due to `index.js` restricting routing to buttons only (`isButton()`).
- Fixed Discord API `400 Bad Request` (`Invalid Form Body - flags`) errors during component interaction updates by stripping `flags` on `editReply` and `update` calls.
- Fixed interaction timeouts during select menu option selection by adding immediate `deferUpdate()` calls.
- Fixed `400 invalid_item_id` errors when querying Bazaar API with uppercase product IDs.
- Fixed Bazaar items (e.g. `Cactus`, `Fermento`) improperly defaulting to 14-day auction average valuations.
- Fixed `Fermento` matching `Fermento Boots` and evaluating at 10M static price.
- Fixed custom-named pets (e.g. `Yoruichi`) failing species detection and displaying as generic or incorrectly valued pets.
- Fixed pet rarity displaying as `[COMMON]` for legendary pets lacking explicit `petRarity` root tags.
- Fixed raw search input strings showing in `/item` and `/auction` component outputs.
