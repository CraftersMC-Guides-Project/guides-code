# Feather Bot 2.0.0

Last commit `50b416e` on 2026-05-19.

Changelog covers everything after `3cc845a93555942bd274e8670ec5ee32a28d5f6f`.

## Detailed Summary

Version 2.0.0 expanded the bot from its 1.0.0 foundation with stronger minion, leaderboard, Bazaar, and CLI tooling. The main user-facing additions were the new top-minion ranking commands, Bazaar item browsing, and a paginated global alias view for Bazaar mappings. The release also made the minion calculator safer by introducing default tier behavior and fixing missing-data cases.

For data and operations, 2.0.0 added CLI workflows for fetching leaderboard data, submitting leaderboard data, and handling collection data. It also added CraftersMC level calculation support and fixed level data handling, making the leaderboard/submission pipeline more complete. Development behavior was tightened by preventing the auction exporter from running in dev.

The Bazaar mapping system also received a usability upgrade. Users can browse all Bazaar items through `/bz items`, and mapping lists now include a `Global Alias` button that opens a 10-item-per-page global alias view. New global aliases can store metadata about who added them while older aliases remain compatible.

## Added

- Added `/top minions` and `/top minion` for ranking minions by estimated 24-hour coin output.
- Added top-minion options for result limit, max tier, fuel, Super Compactor, Diamond Spreading, and Potato Spreading.
- Added paginated container views for top-minion results so longer rankings can be browsed cleanly.
- Added default tier handling for minion calculations, defaulting missing tier input to tier 1.
- Added CraftersMC level calculation support across leaderboard/submission-related flows.
- Added CLI leaderboard fetch commands for pulling leaderboard data into the local `leaderboards/src/lb` files.
- Added CLI leaderboard submission commands for testing/submitting user leaderboard data from the command line.
- Added collection data support to CLI leaderboard workflows.
- Added `/bz items` to list all Bazaar catalog items with pagination.
- Added Bazaar item-list component routing and cache state for item pagination.
- Added a `Global Alias` button to Bazaar mapping list views.
- Added a paginated global Bazaar alias view with 10 aliases per page.
- Added global Bazaar mapping metadata so newly added global aliases can show who added them.
- Added backup user data updates alongside the global mapping view work.

## Changed

- Updated minion calculator internals to work with the new top-minion command and default tier behavior.
- Updated minion command help and routing to account for the new ranking workflow.
- Updated leaderboard storage and parsing for CraftersMC level data.
- Updated leaderboard submission behavior so CLI and Discord submission flows share more complete data handling.
- Updated collection leaderboard data files and backup leaderboard data.
- Updated Bazaar item resolution and API helpers for the new Bazaar item browsing flow.
- Updated Bazaar command help/readme data to include `/bz items`.
- Updated Bazaar mapping storage to support metadata while keeping the old `alias -> itemId` format compatible for existing global aliases.
- Updated component routing in `index.js` for Bazaar item pages and global alias pages.
- Updated account, auction, Bazaar, and notification data snapshots as part of the release data refresh.
- Prevented the auction exporter from running in development mode.

## Fixed

- Fixed the `No minion data found.` case in minion calculations.
- Fixed CLI leaderboard submission behavior.
- Fixed `xpLevelsData` and `levelsData` handling.
- Fixed collection-data CLI handling so collection leaderboard data could be fetched/submitted more reliably.
- Fixed Bazaar item-list interaction handling by routing the new components through the Bazaar command handler.
