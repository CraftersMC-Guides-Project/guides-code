Feather Bot

Concise, copy-ready slash commands for CraftersMC. Styled with the same glassy vibe as SkyCalendar so it feels native to your existing guides.

Invite Feather Bot Github Organisation Need help? Join our discord server.
Accounts & Identity
general

/account

Returns the Discord and Minecraft ID if linked.

/account
operator

/verify

Operator-only: links a Discord user to a Minecraft IGN. Use optional raw Discord ID if mentions are off.

/verify minecraft:<mc> user:<discord> [discord:<id>]
operator

/unlink

Operator-only: removes the Discord ↔ Minecraft association. Supply mention or numeric ID to avoid mistakes.

/unlink user:<discord> [discord:<id>]
owner

/addop

Owner-only: grants operator permissions inside Feather Bot, unlocking all mod tools. Use sparingly.

/addop user:<discord>

Economy & Market
general

/bz item

Shows live buy/sell price, volume, and spread for a single bazaar item. Use exact internal ID (e.g., ENCHANTED_PAPER).

/bz item item:<id>
general

/bz graph

Price history chart for any item; pick a window between 1–180 days. Optional from/to dates let you isolate a patch period.

/bz graph item:<id> [days:1-180] [from_date:YYYY-MM-DD] [to_date:YYYY-MM-DD]
general

/bz flip

Generates a flip suggestion for the chosen item, estimating margin after fees so you can decide quantity and risk.

/bz flip item:<id>
general

/bz top

Ranks bazaar items by profit, volume, or spread—quick scan to pick today’s best flips.

/bz top category:<profit|volume|spread>
general

/bz mapping

Create personal or global aliases so you can type short names instead of full item IDs.

/bz mapping mapping-action:<list|add|remove> scope:<personal|global> [alias:<name>] [item:<id>]
general

/bz alert

Sets, lists, or removes price alerts that DM you when an item crosses a threshold.

/bz alert alert-action:<list|add|remove> [item:<id>] [price:<number>] [direction:<above|below>] [alert-id:<id>]
