Authentication

Public / Scoped API Settings

Authentication & Player API Scopes

Most endpoints in the CraftersMC Public API do not require traditional authorization bearer tokens. However, player profile details, inventories, and SkyBlock member data are subject to Player API Settings. If a target player has disabled specific API settings (e.g. Bank API or Inventory API), those nested fields will be omitted from the JSON payload or return a 403 Forbidden response with error message "Missing required API scope".

Standard response envelopes and error handling contracts implemented across all endpoints.

Standard Error Response Envelope (ApiErrorReply)

When an HTTP error occurs (e.g. 400, 403, 404, 429, or 503), the API returns a unified error JSON envelope:

ApiErrorReply Schema 
{
  "success": false,
  "error": "Player not found",
  "message": "No player matching the given username or UUID could be retrieved."
}
Status Code Description Typical Cause / Mitigation
200 OK Successful Execution The request succeeded and returned the requested data payload.
400 Bad Request Invalid Identifier / Parameters Check input formatting (e.g., UUID format, page number integers).
403 Forbidden Missing API Scope Target player has turned off API access in their SkyBlock settings menu.
404 Not Found Resource Not Found Auction ID, profile ID, or item ID does not exist in the database.
429 Rate Limit Rate Limit Exceeded Too many requests sent in a short window. Implement exponential backoff.
503 Service Unavailable Data Unpopulated / Cache Warming Data list (e.g. voters, active auctions) is warming up or syncing.
